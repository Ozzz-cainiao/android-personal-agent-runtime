# 0.0.5-preview · 首次使用配置引导

下载APK后首次打开即可跟随软件内向导：

1. 打开或安装 Shizuku，查看官方配对与启动教程。
2. 检查服务连接并授权 Personal Agent。
3. 打开淘宝，手动确认登录和运行条件。
4. 完成配置，进入任务页；以后可从“配置检查 / 使用引导”重新打开。

[详细指南](https://github.com/Ozzz-cainiao/android-personal-agent-runtime/blob/main/docs/GETTING_STARTED.md)

已在小米15 Ultra / Android16验证已有Shizuku授权状态检测、勾选门槛和进入任务页。构建、Lint、JVM测试通过。全新设备安装配对及拒绝授权分支尚待实机覆盖。

附件是Debug测试APK，可覆盖同签名旧预览版，不是正式生产签名。每日签到已实测，快速赚仍为实验功能；广告需手动关闭，不支持全套240金币自动化。项目许可证尚未确定。
