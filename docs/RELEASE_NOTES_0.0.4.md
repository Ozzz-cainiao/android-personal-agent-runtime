# 0.0.4-preview：邀请试用

一个轻量的 Android Shizuku 自动化实验。第一条实测流程：打开淘宝 → 进入淘金币 → 每日签到 → 检查结果。

## 开始使用

下载附件 `personal-agent-0.0.4-preview-debug.apk`，按[新手指南](https://github.com/Ozzz-cainiao/android-personal-agent-runtime/blob/main/docs/GETTING_STARTED.md)启动 Shizuku、授权，再点击领取今日淘金币。

## 兼容与限制

- 仅实测小米15 Ultra / Android16；最低安装版本Android9，其他机型待验证。
- 需登录淘宝、解锁亮屏，广告需要手动关闭。
- 快速赚按钮为实验功能：到访与视频任务代码尚待新一天全链路验收。并非自动拿满240金币。
- 无自动解锁、定时、AI、云服务、自动支付。
- 附件是可安装的 Debug 测试包，不是正式生产签名；未来签名变化可能需要卸载旧版。
- 项目许可证待确定，公开源码不代表已授予任意使用和再分发许可。

欢迎在 Issues 提供机型、系统/淘宝版本、步骤及去敏日志。请勿上传账号信息或完整屏幕控件数据。
