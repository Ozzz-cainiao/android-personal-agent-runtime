# 新手使用指南

## 1. 准备

- Android 手机：安装最低 Android 9；目前只实测 Android 16 / 小米 15 Ultra。Android 11+ 可用无线调试启动 Shizuku，不必一直连电脑。
- 已安装并登录淘宝，能手动打开淘金币页面。
- 安装官方 [Shizuku](https://shizuku.rikka.app/)，按[官方启动指南](https://shizuku.rikka.app/guide/setup/)完成启动。

## 2. 启动 Shizuku

Android 11+：开启开发者选项和无线调试，在 Shizuku 中开始配对，使用系统“通过配对码配对设备”显示的配对码，回到 Shizuku 点击启动。看到“正在运行”再继续。重启手机后通常需要重新启动。

也可通过电脑 USB 启动：安装 Android Platform Tools、开启 USB 调试，连接手机并允许调试授权，然后照 Shizuku App 中显示的启动命令操作。无需 root。

小米设备若出现“能启动但无法点击”，检查开发者选项中的 **USB 调试（安全设置）**，它与普通 USB 调试不同。通过电脑安装 APK 被拒绝时，还需检查 **USB 安装**。具体名称以系统实际界面为准；参见官方指南的厂商限制章节。

## 3. 安装预览版

到本仓库 [Releases](https://github.com/Ozzz-cainiao/diandao/releases) 下载 `.apk` 附件，不是 Source code 压缩包。手机打开 APK，按提示允许该下载来源安装应用。当前为 Debug 测试包；仅从本仓库下载。

若提示签名冲突，先确认旧版来源。预览版没有需保留的任务数据库，卸载旧版再装会清除本 App 日志和私有诊断文件，不影响淘宝账号。

## 4. 软件内配置（0.0.5 起）

首次打开自动显示配置向导。按页面按钮打开 Shizuku 或官网下载页、查看配对教程、授权，并打开淘宝确认登录。回到向导后状态会刷新，也可点“重新检查配置”。服务连接、授权、淘宝安装和准备确认均满足后，才能点“完成配置，进入任务”。完成记录保存在本机；任务页的“配置检查 / 使用引导”可重新打开向导。

配置页不会自动执行任务，也无法代替你确认淘宝登录。重启后若 Shizuku 停止，需要重新启动服务；完成过向导不代表服务永久有效。

## 5. 首次连接

1. 解锁手机，保持亮屏，确认 Shizuku 正在运行。
2. 打开 点到，点击“测试 Shizuku 连接”。
3. 在 Shizuku 授权弹窗中允许。未出现弹窗时查看 Shizuku 的应用管理。
4. 日志出现 `[通过] UserService uid=2000` 表示 shell 服务连接成功；root 模式可能显示 0。

## 6. 每日签到

1. 先关闭淘宝广告弹窗，回到淘宝首页。
2. 回到 点到，点击“签到并返回桌面”。
3. 等待约数秒至数十秒，不要干预屏幕。App 会启动淘宝、进入淘金币、签到一次并检查页面。
4. 返回 点到 查看结果。已签到应显示“今日已签到，无需重复领取”。若失败，请查看淘宝页面再决定是否重试。

“快速赚金币（测试）”仍是实验功能，目前代码只支持到访和好物沉浸看，不代表能自动拿满240金币。它先运行每日签到流程，再进入快速赚面板。任务名称变化或无法验证结果会停止。请勿据此预期固定收益。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| Shizuku 未连接 | 打开 Shizuku 重新启动，并检查授权 |
| 目标 App 未处于前台 | 解锁手机，关闭遮挡页面后重试 |
| 未确认淘金币页面 | 检查广告、登录状态或页面改版；当前不会自动关广告 |
| 找不到任务/没有支持的待领奖任务 | 任务可能已完成或活动已更换，不会盲点其他任务 |
| 页面显示成功但日志失败 | 保存去敏日志与步骤反馈，不要不断重复点击 |
| 切到淘宝后流程停住 | 保持亮屏；检查系统是否限制 App/Shizuku 后台运行 |

取消：返回 点到 点击“取消任务 / 断开连接”。退出并卸载本 App 可删除其私有诊断数据；也可以在 Shizuku 中撤销授权。
